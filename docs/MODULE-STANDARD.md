# Interactive module standard (`getmatchready.module/v1`)

This is the house standard for interactive modules — the Captivate-style format we
want every module to follow, whether authored by hand or generated by the AI course
builder. When the player or the format changes, update this doc **and** the AI
prompt in `lib/aicourse.js` (`buildModulePrompt`) so generated courses stay on
standard.

## Experience

- **Left progress panel**, not a top bar: a "Course progress" bar that advances on
  every completed interaction, over a labelled list of sections (green when done,
  accent when current, grey ahead), with a connecting line that fills as you go.
- **Full screen** is available on every module (⛶ button, top-right).
- **One idea per section.** Pages are short and scannable; a long topic is several
  short sections, not one dense page.
- **Title + subtitle.** Every standard page has a punchy `title` (2–5 words) and a
  one-line `subtitle` (6–14 words) that frames the page — not a repeat of the title.
  Headings use a display face (Archivo); subtitle is a lighter lead line.
- **Lead with the visual or video, then the teaching text.**
- Plain, encouraging, second-person coaching voice.

## Media

- **Images:** referee photos via `graphic` (one of the known keys) plus an
  `imageBrief`. Non-refereeing topics omit `graphic`.
- **Video:** only when a **real URL** exists.
  - `narration.videoUrl` or `videoDecision.clipUrl` = a full `https` link to an
    `.mp4`, or a YouTube/Vimeo page (auto-embedded 16:9).
  - If there is no real URL, **omit the field** and do not reference "watch the
    video" in text — teach with prose, a scenario, or a described decision. Never
    invent a URL.

## Blocks (pick the right one)

| Intent | Block |
|---|---|
| Key rule / must-know | `callout` |
| Optional "expand for detail" | `accordion` |
| Flip-to-reveal definitions/terms | `flashcards` |
| Switch between parallel facets | `tabs` |
| A standalone picture | `image` (`imageUrl` + `caption?`) |
| Short sequence of steps | `carousel` |
| Yellow-vs-red style contrast | `compare` |
| A situation to reason about | `scenario` |
| "What do I do when…" decision logic | `flow` (renders as a real flowchart) |
| Run-one-scenario capstone (FULL only) | `branching` (wrong answer explains + retry) |
| Voiceover script or a real video | `narration` (+ `videoUrl`) |
| Check understanding (gated) | `knowledgeCheck` (`gateRevealBehindSubmit:true`) |
| Decision from a clip/scene | `videoDecision` (+ `clipUrl` when real) |
| End of a FULL lesson | `summary` + `assessment` (6–10 items, 80% pass) |
| End of a TENT TALK | `checklist` (`id:"ack"`), page `completionRequires:["ack"]` |

**Interactive variety, every time.** A course should feel like a polished
Captivate/US-Soccer course, not walls of prose — in BOTH modes. Use a mix of the
blocks above with an interactive/visual block on most pages; include at least one
`flashcards` or `tabs`, and a `flow` where there's decision logic. The banner,
display headings, subtitles and progress UI are styled automatically by the
player — author strong content and this variety.

## Flowchart standard (`flow`)

Reproduce this shape every time: one `start` node (the trigger) → alternate
`decision` nodes (each a clear either/or or yes/no question) with the `outcome`(s)
they lead to → one `end` node (the final action). Every decision has exactly **2
branches**; each branch's `answer` is the short choice and its `to` names where
that path leads in a few words (rendered as "[answer] → where it leads"). Keep the
flow to **4–7 nodes**. Use it for a genuine judgement call, never to list facts.
Locked into `lib/aicourse.js`.

## Two modes

- **Tent Talk** — a ~5-minute, tournament-side **information session**. Informational
  blocks only; **no** graded blocks (`knowledgeCheck`, `videoDecision`, `imageSelect`,
  `branching`, `assessment`). Enforced server-side by `enforceInfoSession`.
  Plays as a **presentation**: an info session gets the `gmr-present` class, so in
  full screen the left progress rail is hidden, the slide fills the width, and
  Back/Next are pinned to the bottom (PowerPoint-style).
- **Full lesson** — teaches across several pages with a gated `knowledgeCheck` on
  most content pages and a final `summary` + `assessment`. Keeps its progress rail.

## Where it lives

- Player/renderer: `renderModuleLesson` in `public/app.js`; styles under `.gmr-*`
  in `public/styles.css`.
- Server-side normaliser / gatekeeper: `lib/moduledoc.js`.
- AI generation + this standard, in prompt form: `lib/aicourse.js`.
